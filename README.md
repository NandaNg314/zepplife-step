# 微信步数修改同步助手 (Zepp Life / Vercel 版)

轻量、现代化的微信步数修改工具，基于 Zepp Life 官方云端接口协议，专为 Vercel Serverless Function 架构设计。
  
---

## 🌟 特性

- **零依赖 (0 Dependencies)**：使用原生 Node.js 与内置 `fetch`，无需安装任何 npm 第三方依赖，Vercel 部署 **秒级完成**，彻底告别依赖冲突。
- **动态专属虚拟手环**：为每个账号基于 UID 独立散列生成唯一的虚拟手环设备识别号与 MAC 地址，杜绝多账号全局撞车。
- **现代化 Web UI**：深色玻璃拟态设计，自适应手机和电脑屏幕，支持步数快捷预设与本地记住账号。
- **支持 API / 快捷指令**：支持 `GET` 和 `POST` 请求，轻松接入 iOS 快捷指令（Shortcuts）或定时脚本。
- **完整手环协议模拟**：包含心率数据与活动区间模拟，通过率高，不易被风控判定为异常包。

## 🚀 部署与使用方案

### 方式一：Vercel 部署（云端无服务器）

1. **推送代码至 GitHub**：
   ```bash
   git add .
   git commit -m "update: sync and optimize step script"
   git push origin main
   ```
2. **在 Vercel 导入并部署**：
   - 登录 [Vercel 官网](https://vercel.com)。
   - 点击 **Add New...** -> **Project**，导入仓库，点击 **Deploy** 即可。

> [!IMPORTANT]
> **关于国内网络“Vercel 打不开 / 连不上”的问题**：
> Vercel 默认分配的 `*.vercel.app` 免费域名在大陆大部分地区被 DNS 污染与 SNI 阻断，因此手机或直连访问会提示连接超时或无法打开。
> **解决方法**：
> 1. **绑定个人自定义域名（强烈推荐，一劳永逸）**：在 Vercel 项目页面点击 **Settings** -> **Domains**，绑定二级域名（如 `step.yourdomain.com`），并将域名解析添加 CNAME 指向 `cname.vercel-dns.com`。自定义域名在国内各大运营商网络均可极速秒开。
> 2. **开启科学上网/代理**：临时使用代理即可正常访问 `*.vercel.app`。
> 3. **改用本地或 VPS 免翻墙运行**（见下文方式二）。

---

### 方式二：本地免翻墙直接运行（极简）

如果你暂时没有自定义域名，可以直接在电脑或轻量服务器运行项目自带的 `server.js`，完全不走 Vercel，不依赖翻墙：

```bash
# 启动本地服务
node server.js
```

启动后在浏览器打开 `http://localhost:3000` 即可直接使用！手机在同一局域网下访问电脑 IP（例如 `http://192.168.1.x:3000`）也能直接操作。

## 💡 API 调用与 iOS 快捷指令

除了直接访问网页，你还可以将接口加入 iOS 快捷指令，实现点一下图标自动刷步数：

### GET 请求示例：

```http
GET https://你的域名/api/step?user=你的账号&password=你的密码&steps=23888
```

- `user`：Zepp Life 注册账号（**强烈建议使用邮箱**）
- `password`：账号密码
- `steps`：目标步数（可选，留空则随机生成 18,000 ~ 26,000 之间的合理步数）

### 返回结果：

```json
{
  "code": 200,
  "success": true,
  "message": "步数修改成功！微信可能需要几分钟同步",
  "data": {
    "account": "user@example.com",
    "steps": 23888,
    "date": "2026-09-24",
    "time": "2026-09-24 18:50:00"
  }
}
```

## 🔍 核心技术问答与排查指南

### Q1：为什么用“别人的账号”可以同步，但自己的 3 个账号每次绑定都不行？

这是华米（Huami/Zepp）步数同步中最常见且最具迷惑性的问题，核心原因如下：

1. **微信端的“旧设备占坑与缓存串号”（最主要原因）**：
   - 微信运动底层规定：**一个微信号的数据来源只能绑定一个有效的手环硬件设备**。
   - 当你之前用微信成功绑定了“别人的账号（设备）”后，微信后台数据库已经将你的微信 OpenID 与该设备永久绑定。
   - 之后哪怕你在 App 里退出登录，换了你自己的账号并点击“绑定微信”，**微信后台并没有真正释放旧设备的授权**，它依然在监听那个生效的旧设备！
   - 只要你提交“别人的账号”，微信能更新；而提交你的 3 个新账号，微信认为不是绑定的设备，直接丢弃！
   - **彻底清缓存与解绑方法**：
     - 打开微信 -> 进入【微信运动】公众号 -> 点击右上角齿轮 ⚙️【设置】 -> 【数据来源】。
     - 查看列表中是否有之前的“华米科技”或“跃我”或旧设备，点击进入并**解除绑定 / 取消授权**。
     - 搜索并进入【华米科技】和【Amazfit跃我】公众号，点击右上角 `...` -> **不再关注并清空内容**。
     - 彻底解绑并清理后，再登录你自己的账号重新授权绑定。

2. **新账号的风控拦截（云端硬件过滤）**：
   - 能同步成功的“别人的账号”，绝大多数是**历史老账号**，或者**名下曾真正连接过实体手环/手表物理硬件**。
   - 华米云端有一套反刷单风控机制：空头新账号在调用接口时，华米服务器虽然返回 `code: 1, message: "success"`，但华米在向微信运动推送数据时，**会把名下没有真实物理设备记录的新账号静默过滤**。

3. **App 混淆：Zepp Life 与 Zepp 的区别**：
   - **Zepp Life（原小米运动）**：目前已停止大规模维护，绑定的是【华米科技】公众号，接口老旧且极易风控抽风。
   - **Zepp（原 Amazfit 跃我）**：华米目前的核心官方应用，绑定的是【Amazfit 跃我】公众号，走的是微信硬件平台直通协议。很多刷步平台（如 `go.yomia.cn`）后台推荐的均是 **Zepp** 而非 Zepp Life。

4. **像 `go.yomia.cn` 这类网站背后的原理是什么？**
   - 经过逆向分析，此类平台采用的是**“官方公共设备池 + 微信硬件扫码绑定”**模式。
   - 平台后台准备了一批信誉良好、已激活手环的公共老账号。
   - 用户打开网站时，平台动态下发一个包含 `ticket` 的微信设备绑定二维码，用户扫码后微信直接绑到平台的公用设备上；
   - 随后用户提交步数，平台是用**平台自己的老账号**去推送步数的，因此用户甚至不需要自备账号就能秒同步。
