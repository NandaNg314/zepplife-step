# 微信步数修改同步助手 (Zepp Life / Vercel 版)

一个用于诊断 Zepp Life 数据同步的本地工具。它依赖未公开的兼容接口，接口、账号地区、已绑定设备和微信侧授权都会影响结果，不能承诺修改后一定会显示在微信运动中。
  
---

## 🌟 特性

- **零依赖 (0 Dependencies)**：仅使用原生 Node.js 的 `https` 与 `crypto` 模块，无需安装 npm 第三方依赖。
- **已验证设备检查**：优先使用已启用设备；只有用户明确选择后，才会注册测试设备，并在服务端回读确认成功后提交数据。
- **现代化 Web UI**：深色玻璃拟态设计，自适应手机和电脑屏幕，支持步数快捷预设与本地记住账号。
- **支持 API / 快捷指令**：支持 `GET` 和 `POST` 请求，轻松接入 iOS 快捷指令（Shortcuts）或定时脚本。
- **账号隔离**：网页不缓存 Zepp 的业务 token；每次提交均按当前填写的账号登录，避免切换账号时串号。
- **可诊断失败原因**：会区分输入、登录节点、设备未绑定和提交失败等错误，不会把失败伪装成成功。

## 🚀 部署与使用方案

### 方式一：Vercel 部署（云端无服务器）

1. **推送代码至 GitHub**：
   ```bash
   git add .
   git commit -m "update: sync and optimize step script"
   git push origin main
   ```
2. **在 Vercel 导入并部署**：
   - 登录 [Vercel 官网](https://vercel.com)。
   - 点击 **Add New...** -> **Project**，导入仓库，点击 **Deploy** 即可。

> [!IMPORTANT]
> **关于国内网络“Vercel 打不开 / 连不上”的问题**：
> Vercel 默认分配的 `*.vercel.app` 免费域名在大陆大部分地区被 DNS 污染与 SNI 阻断，因此手机或直连访问会提示连接超时或无法打开。
> **解决方法**：
> 1. **绑定个人自定义域名（强烈推荐，一劳永逸）**：在 Vercel 项目页面点击 **Settings** -> **Domains**，绑定二级域名（如 `step.yourdomain.com`），并将域名解析添加 CNAME 指向 `cname.vercel-dns.com`。自定义域名在国内各大运营商网络均可极速秒开。
> 2. **开启科学上网/代理**：临时使用代理即可正常访问 `*.vercel.app`。
> 3. **改用本地或 VPS 免翻墙运行**（见下文方式二）。

### 方式二：本地免翻墙直接运行（极简）

如果你暂时没有自定义域名，可以直接在电脑或轻量服务器运行项目自带的 `server.js`，完全不走 Vercel，不依赖翻墙：

```bash
# 启动本地服务
node server.js
```

启动后在浏览器打开 `http://localhost:3000` 即可直接使用！手机在同一局域网下访问电脑 IP（例如 `http://192.168.1.x:3000`）也能直接操作。

## 💡 API 调用与 iOS 快捷指令

除了直接访问网页，你还可以将接口加入 iOS 快捷指令，实现点一下图标自动刷步数：

### POST 请求示例：

```http
POST /api/step
Content-Type: application/json

{"user":"你的账号","password":"你的密码","steps":23888,"allow_virtual_device":false}
```

- `user`：Zepp Life 注册账号（**强烈建议使用邮箱**）
- `password`：账号密码；不要放在 URL 查询参数中，以免被浏览器、代理或平台日志记录
- `allow_virtual_device`：默认 `false`。仅当你明确同意注册一个测试设备到自己的 Zepp 账号时才设为 `true`；接口会回读验证，验证失败不会上传步数。
- `steps`：目标步数（可选，留空则随机生成 18,000 ~ 26,000 之间的合理步数）

网页不会缓存 Zepp 的 `app_token` 或 `user_id`；每次提交都会按当前填写的账号重新登录。这会比 token 快捷提交稍慢，但可避免在同一浏览器切换账号时发生串号。

### 返回结果：

```json
{
  "code": 200,
  "success": true,
  "message": "Zepp 数据已提交（微信展示仍取决于官方同步）",
  "data": {
    "account": "user@example.com",
    "steps": 23888,
    "date": "2026-09-24",
    "time": "2026-09-24 18:50:00"
  }
}
```

## 🔍 当前版本的工作方式与排查

### 一次提交会做什么？

1. 校验步数：可提交 `1` 到 `98800` 的整数；留空时生成 `18000` 到 `26000` 的随机值。
2. 使用本次请求填写的 Zepp Life 账号和密码完成登录，并取得该账号的业务凭据与用户 ID。
3. 查询该账号已启用的设备，优先使用第一个可用设备上传当天数据。
4. 只有在没有可用设备且你勾选“同意注册测试设备”时，才会为**当前登录的账号**注册一个测试设备，并立即回读确认它已启用。
5. 向 Zepp Life 的数据接口提交步数。接口返回成功仅表示 Zepp 侧接受了数据；微信运动是否显示仍取决于官方账号授权和同步状态。

### 切换账号会串号吗？

不会。当前版本不会在浏览器中保存或回传 `app_token`、`user_id`，每次点击“立即修改步数”都会用当前输入的账号密码重新登录。因此账号 A 的登录状态不会被拿去给账号 B 上传。

升级旧版本后，请至少刷新一次页面；新页面会清理旧版本遗留的浏览器会话 token。

### 什么时候要勾选“同意注册测试设备”？

仅在当前账号没有任何可用设备、并且你愿意让项目修改该账号的设备列表时才勾选。它不是每次都需要勾选：找到已启用设备时，项目会直接使用该设备，不会重复注册测试设备。

### 为什么会提示超时或登录失败？

项目会依次尝试多个 Zepp Life 登录和数据节点。网络抖动、节点限流或服务端暂时不可用都会导致“登录节点均受限或异常”“请求超时”等提示；这类提示不等同于密码错误。只有明确提示“Zepp Life 账号或密码错误”时，才需要核对账号、独立登录密码和账号类型。

请不要连续高频重试；等待一段时间后再试。若所有节点持续失败，请先确认 Zepp Life 官方 App 能否正常登录和同步。

### 为什么网页提示成功，微信运动却没变化？

网页成功只代表本项目收到 Zepp 数据接口的成功响应，不代表微信已展示。请在 Zepp Life 官方 App 中确认对应账号的设备和微信运动授权仍正常，然后等待官方同步完成。Zepp Life（原小米运动）与 Zepp（Amazfit 跃我）是不同的账号与设备体系，本项目只适用于 Zepp Life 兼容接口。

### 账号与隐私

网页只会在本次请求中提交你填写的账号和密码，不保存密码，也不保存 Zepp 的业务 token。请将项目部署为仅自己可访问的站点，不要将公开地址、账号密码或接口请求分享给他人。
